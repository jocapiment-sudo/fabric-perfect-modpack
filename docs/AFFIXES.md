# Affix reference

> Generated by `npm run docs:affixes` from `src/core/affixes.ts` and `src/core/rarity.ts`.
> Do not edit this file by hand — edit the TypeScript and regenerate.

Every number below is the *base* roll. Item level adds up to +50 % on top
(see `levelMultiplier` in `src/core/affixes.ts`), which is why a freshly
reforged Mythic weapon can beat a low-level one of the same rarity.

## Rarity ladder

| Rarity | Tier | Affix slots | Reforge cost | Upgrade cost | Loot weight | Salvage |
| --- | --- | --- | --- | --- | --- | --- |
| Common | 0 | 0 | 1 dust + 1 lvl | 2 dust + 1 lvl + orb | 45 | 0–1 dust, 0% gem |
| Uncommon | 1 | 1 | 2 dust + 1 lvl | 4 dust + 1 lvl + orb | 28 | 1–2 dust, 25% gem |
| Rare | 2 | 2 | 4 dust + 2 lvl | 8 dust + 2 lvl + orb | 17 | 2–4 dust, 35% gem |
| Epic | 3 | 3 | 7 dust + 3 lvl | 14 dust + 3 lvl + orb | 8 | 4–6 dust, 50% gem |
| Mythic | 4 | 4 | 10 dust + 4 lvl | — | 2 | 6–9 dust, 65% gem |

Upgrades consume one orb of the *target* rarity band: taking an item from Uncommon to
Rare costs a Rare Orb, Rare to Epic costs an Epic Orb, Epic to Mythic costs a Mythic Orb.
Mythic is the top of the ladder and cannot be upgraded further, only reforged.

## How a name is built

```
Keen Diamond Sword of the Berserker
^^^^ prefix            ^^^^^^^^^^^^^^ suffix
```

Only the first prefix and the first suffix appear in the title; every affix is
listed in the lore with its rolled value. Items always roll at least one prefix
when they have an affix slot, so names never read oddly (see `rollAffixes`).

## Affix payload

Affixes are stored on the item itself in the `apoth:item` dynamic property, so they
survive being traded, stored in a chest, or dropped on the ground:

```json
{ "v": 1, "r": "rare", "l": 24, "a": [{ "id": "keen", "v": 0.12 }], "b": [], "n": "Keen Iron Sword" }
```

| Field | Meaning |
| --- | --- |
| `v` | payload version (bumped if the format ever changes) |
| `r` | rarity key: `common`, `uncommon`, `rare`, `epic`, `mythic` |
| `l` | item level, used to scale affix potency |
| `a` | rolled affixes (`id` + rolled value `v`) |
| `b` | socketed gems, each `{ "i": "<affix id>", "r": "<rarity>" }` |
| `n` | cached display name (stripped of formatting codes) |
